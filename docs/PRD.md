# AI開発図鑑 PRD

## 目的

Ruby on Railsの転職・副業案件獲得用ポートフォリオを主目的とし、実ユーザーによる継続運用を副目的とする。日本語のAI開発者がMCP、Skills、Zenn、Qiitaの情報を横断検索し、出典付きAI要約から元情報へ移動できるサービスを提供する。

## 成功条件

- 公開検索から詳細、登録、ブックマーク、マイページまで動作する
- 管理者が手動登録と自動取込候補をレビューして公開できる
- MCP、Skills、Zenn、Qiitaを各100件以上、AI要約・管理者承認後に公開する
- 5人以上の外部テスターが登録・ブックマークする
- 日次自動取込が7日連続で成功する
- CI、アーキテクチャ、運用証拠を公開リポジトリで説明できる

## MVPスコープ

- MCP、Skills、Zenn、Qiita
- メール確認付きメール/パスワード認証とGoogle OAuth
- ブックマーク、非表示、マイページ
- 種類、カテゴリ、タグ、日付、人気度による横断検索
- 説明可能なコンテンツベース推薦
- 管理画面による手動登録、差分レビュー、承認、公開、却下、アーカイブ
- GitHub API、Qiita API、Zenn RSSからの自動取込
- NVIDIA NIMによるバックエンド要約
- SSR、canonical、sitemap、OGP、構造化データ
- Render、Supabase、Cloudflare R2/DNS、Resend、GAS監視

## MVP対象外

- プロンプト、Reddit、Stack Overflow
- ユーザー投稿
- 外部記事本文の保存・再配信
- ベクトル検索、協調フィルタリング
- Vercel、Next.js、Redis、Upstash
- 課金、広告、多言語、ネイティブアプリ

## 不変条件

- 自動取込とAI要約だけで公開しない
- 承認済みRevisionだけを公開する
- 自動更新で現在の公開版を直接上書きしない
- 外部記事本文は永続化しない
- 出典URL、取得日時、AI生成条件を追跡できる
- 管理操作を監査ログへ残す

## UI/UX

- ライト、ダーク、システム設定を提供する
- 検索欄を主要導線とし、選択中フィルターと解除操作を常に明示する
- デスクトップは左フィルターと1列の検索結果、モバイルはボトムシートを使用する
- WCAG AA相当のコントラストとキーボード操作を維持する

## 実装順

1. Resource/Revisionと公開不変条件
2. 認証、管理者認可、レビュー
3. 公開一覧、詳細、検索
4. 外部取込とAI要約
5. ブックマーク、非表示、推薦
6. SEO、R2、Render、GAS監視
7. 初期データ、外部テスト、運用証拠
